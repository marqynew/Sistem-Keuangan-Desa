# Sistem Keuangan Desa

Aplikasi CLI untuk mengelola keuangan desa, memungkinkan pengguna untuk menambah, melihat, mengedit, dan menghapus transaksi keuangan.

## Fitur

- Menambah transaksi keuangan
- Melihat daftar transaksi
- Mencari transaksi berdasarkan ID
- Mengedit transaksi yang ada
- Menghapus transaksi
- Menghasilkan laporan ringkasan
- Mengekspor data ke format CSV

## Persyaratan

- Java 11 atau lebih tinggi
- Maven (untuk mengelola dependensi)

## Instalasi

1. Clone repositori ini:
   ```bash
   git clone https://github.com/username/sistem-keuangan-desa.git
   cd sistem-keuangan-desa
   ```

2. Build proyek menggunakan Maven:
   ```bash
   mvn clean install
   ```

## Menjalankan Aplikasi

Setelah instalasi, jalankan aplikasi dengan perintah berikut:

```bash
java -jar target/sistem-keuangan-desa-1.0-SNAPSHOT.jar
```

## Penggunaan

- Ikuti instruksi yang muncul di CLI untuk menambah, melihat, mengedit, atau menghapus transaksi.
- Gunakan opsi menu untuk menghasilkan laporan atau mengekspor data.
